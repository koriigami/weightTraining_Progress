# Levl sounds: sources and licences

Every file here is CC0 (public domain dedication, https://creativecommons.org/publicdomain/zero/1.0/). No credit is required; we credit the authors anyway.
Each file was trimmed, turned to mono and levelled with ffmpeg (EBU R128 momentary loudness, with a limiter); music beds are cut on bar lines so they loop. Nothing else was changed.
Key and contour come from `tools/contour.py` in the board 12 working files: a pitch track and a chroma profile per sound, used to keep only rising, major-key sounds for good moments.
