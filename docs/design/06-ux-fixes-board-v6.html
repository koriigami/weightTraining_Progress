UX Fixes Board v6

Fixes from using the app day to day. Same Arena Bright look and Deep Sky hero as board 05. Every screen below is a real state you will hit, shown side by side. The ones marked "Try it" respond to taps.

Nothing starts by accidentEmpty workout and cardio open a picker first. The clock only runs after you tap Start workout.

Center button

Home

The Today card replaces Up next and the yellow Empty workout block. It has three states. Start the suggested routine in one tap, or pick something else right under it.

Starting a workout

The center button says what it does. Its sheet lists your routines, cardio, and Empty workout, each with a line that explains it.

Logging

The stats row shows what matters for what you're logging. A chip shows how close you are to the finish bonus, and exercises show when you beat last time or set a record.

Past workouts

Cards open a workout page. Everything can be edited there with the same layout as logging, just without a running clock. Delete asks first.

Routines and Rank

Tabs sit in the pinned header, so they never scroll away. Scroll these phones to check.

Profile, onboarding and dates

A real month on Profile, Skip moved out of Continue's way, and one date picker in the game style that opens inside the sheet you're in.

Desktop

The same fixes at desktop width. The header row and side column stay put while the main column scrolls.
